# @samuelfabel/plugin-grpc-docs

Frontend plugin that registers an `ApiDefinitionWidget` for `spec.type: grpc`.

```bash
yarn --cwd packages/app add @samuelfabel/plugin-grpc-docs
```

Wire `grpcApiWidget` into `apiDocsConfigRef` — see [examples/app-wiring.md](../../examples/app-wiring.md).

Project docs: [docs/](../../docs/).
